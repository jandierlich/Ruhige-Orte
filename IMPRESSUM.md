## Datenschutz

### 1. Keine Cookies, kein Tracking

Diese App setzt keine Cookies. Es werden keine Tracking-Tools wie Google Analytics, Matomo oder ähnliches verwendet. Es gibt kein Backend, keinen Server, der Zugriffe loggt (außer GitHub Pages selbst – siehe 4).

### 2. Standort

Die Standortfunktion nutzt die Browser-API `navigator.geolocation`. Der Standort wird ausschließlich lokal im Browser verarbeitet, um die Entfernung zu ruhigen Orten zu berechnen (Haversine Formel lokal). Der Standort wird niemals an einen Server gesendet oder gespeichert.

Speicherung lokal:
- `ruhige-orte-favs` – Favoriten (localStorage)
- `ruhige-orte-notes` – persönliche Notizen (localStorage)
- `ruhige-orte-checks` – Ruhe-Checks (localStorage)
- `ruhige-orte-theme` – Hell/Dunkel (localStorage)

Alle Daten bleiben auf dem Gerät und können im Browser unter Website-Daten gelöscht werden.

### 3. Karten & Suche

**Karten:** Leaflet mit Tiles von CARTO basierend auf OpenStreetMap Daten. Beim Laden der Karte werden Kacheln von `basemaps.cartocdn.com` geladen. Dabei wird die IP-Adresse an CARTO übertragen (technisch notwendig). Es gelten: https://carto.com/privacy/

**Suche (optional):** Nur wenn du auf "Suchen" klickst, wird der eingegebene Ort an Nominatim (nominatim.openstreetmap.org) gesendet. Es gelten die OSM Bedingungen: https://operations.osmfoundation.org/policies/nominatim/ – Bitte nur sparsam nutzen.

### 4. GitHub Pages

Diese Seite wird über GitHub Pages gehostet. GitHub kann technisch bedingt IP-Adressen und Zugriffszeiten loggen. Siehe GitHub Privacy: https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement

### 5. Deine Rechte

Du hast das Recht auf Auskunft, Löschung deiner lokal gespeicherten Daten (einfach im Browser löschen) und Beschwerde bei einer Aufsichtsbehörde.
