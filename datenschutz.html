Datenschutz

1. Keine Cookies, kein Tracking

Diese App setzt keine Cookies. Es werden keine Tracking-Tools wie Google Analytics, Matomo oder ähnliche verwendet. Es gibt kein Backend und keinen Server, der Zugriffe loggt (außer GitHub Pages selbst – siehe Punkt 4).

2. Standort & lokale Speicherung

Die Standortfunktion nutzt die Browser-Schnittstelle navigator.geolocation. Der Standort wird ausschließlich lokal im Browser verarbeitet, um die Entfernung zu ruhigen Orten zu berechnen. Er wird niemals an einen Server gesendet oder gespeichert.

Folgende Daten werden lokal im Browser gespeichert (localStorage):

  • ruhige-orte-favs – Favoriten
  • ruhige-orte-notes – persönliche Notizen
  • ruhige-orte-checks – Ruhe-Checks
  • ruhige-orte-photos – eigene Fotos zu Orten (nur auf diesem Gerät, verkleinert)
  • ruhige-orte-custom – übernommene OSM-Orte
  • ruhige-orte-theme – Hell/Dunkel-Einstellung

Alle Daten bleiben ausschließlich auf deinem Gerät und lassen sich im Browser unter „Website-Daten“ jederzeit löschen.

3. Karten & Suche

Karten: Die App nutzt Leaflet mit Kartenkacheln von CARTO auf Basis von OpenStreetMap-Daten. Beim Laden der Karte werden Kacheln von basemaps.cartocdn.com geladen, dabei wird die IP-Adresse technisch bedingt an CARTO übertragen. Es gelten die Datenschutzbestimmungen von CARTO.

Bibliothek: Die Kartendarstellung nutzt die JavaScript-Bibliothek Leaflet, ausgeliefert über unpkg.com (CDN). Dabei wird die IP-Adresse technisch bedingt an unpkg.com übertragen.

Ortssuche (optional): Nur wenn du aktiv auf „Suchen“ klickst und den Hinweis bestätigst, wird der eingegebene Ort an Nominatim (nominatim.openstreetmap.org) gesendet. Es gelten die Nutzungsbedingungen von Nominatim.

Live-Suche (optional): Nur wenn du aktiv auf „Live: Orte, Cafés & Eis hier finden“ klickst und den Hinweis bestätigst, wird der aktuelle Kartenausschnitt an einen von mehreren öffentlichen Overpass-Servern gesendet (der Reihe nach versucht: overpass-api.de, overpass.kumi.systems, overpass.private.coffee – alle OSM-Community-Dienste, falls einer nicht erreichbar ist). Es gelten die Nutzungsbedingungen der Overpass API.

Wetter (optional): Nur wenn du bei einem Ort aktiv auf „Wetter hier abrufen“ klickst und den Hinweis bestätigst, werden die Koordinaten dieses Ortes an Open-Meteo (api.open-meteo.com) gesendet, um die aktuelle Temperatur, Windgeschwindigkeit und den Niederschlag abzurufen. Open-Meteo ist ein kostenloser Wetterdienst ohne Login und ohne Tracking. Es gelten die Nutzungsbedingungen von Open-Meteo.

4. GitHub Pages

Diese Seite wird über GitHub Pages gehostet. GitHub kann technisch bedingt IP-Adressen und Zugriffszeiten protokollieren. Siehe die GitHub-Datenschutzerklärung.

Du hast das Recht auf Auskunft und Löschung deiner lokal gespeicherten Daten (einfach im Browser löschen) sowie das Recht zur Beschwerde bei einer Datenschutz-Aufsichtsbehörde.
